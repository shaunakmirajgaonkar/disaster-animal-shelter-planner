# Data Dictionary

| Field | Meaning |
|---|---|
| record_id | Unique row identifier |
| zone | Evacuation/planning zone |
| site_name | Temporary shelter facility |
| animal_type | Animal category |
| animal_count | Animals expected/intended for this record |
| evacuation_priority | Locally assigned planning priority |
| transport_capacity | Animals that can be transported into the site planning window |
| travel_minutes | Estimated local travel time |
| facility_capacity | Maximum planned animal spaces |
| current_booked | Existing/committed animal spaces |
| water_capacity_l_day | Daily water capacity available |
| feed_capacity_kg_day | Daily feed capacity available |
| backup_power_hours | Backup power runway |
| handling_staff | Available handling staff |
| crate_pen_availability | Available crates/pens |
| veterinary_support | Veterinary support level (0–2) |
| livestock_support | Livestock handling support level (0–2) |
| last_inspection_days | Days since last local facility inspection |
